Photosynthèse – SVT 5ème

Nutrition des plantes, lumière, chlorophylle

1. Définition

La photosynthèse est le processus par lequel les plantes fabriquent leur propre matière organique à partir de matière minérale, en utilisant l'énergie lumineuse.

CO₂ + H₂O + lumière → Glucose (C₆H₁₂O₆) + O₂
Les plantes sont dites autotrophes : elles se nourrissent elles-mêmes.

2. Lieu de la photosynthèse

La photosynthèse a lieu dans les chloroplastes, organites des cellules végétales contenant la chlorophylle.

La chlorophylle est le pigment vert qui absorbe la lumière (surtout rouge et bleu) et réfléchit le vert → les feuilles sont vertes.

Sans lumière, la photosynthèse s'arrête. Une plante privée de lumière jaunit et dépérit.

3. Matières premières et produits

Entrées (matières premières)Sorties (produits)
CO₂ (dioxyde de carbone) — absorbé par les stomatesGlucose (matière organique)
H₂O (eau) — absorbée par les racinesO₂ (dioxygène) — rejeté dans l'air
Lumière — captée par la chlorophylle

4. Rôle dans la chaîne alimentaire

Les plantes sont les producteurs primaires : elles fabriquent la matière organique à la base de toutes les chaînes alimentaires.

Les animaux sont hétérotrophes : ils doivent consommer d'autres organismes pour se nourrir.

Chaîne alimentaire : Plante (producteur) → Herbivore (consommateur 1) → Carnivore (consommateur 2)
