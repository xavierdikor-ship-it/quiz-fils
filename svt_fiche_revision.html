🔑 Vocabulaire clé

Stimulus
Modification de l'environnement qui provoque une réaction de l'organisme.
Ex : lumière, son, douleur.
Neurone
= Cellule nerveuse. Il propage les messages nerveux.
Composé de : dendrites → corps cellulaire (+ noyau) → axone → terminaisons.
Nerf
Faisceau de centaines de milliers d'axones regroupés.
⚠️ Un nerf ≠ un neurone.
Synapse
Zone de contact entre les terminaisons d'un neurone et d'une autre cellule.
Neurotransmetteur
Messager chimique libéré dans la synapse pour transmettre le message au neurone suivant.
Neurone pré-synaptique
1er neurone → celui qui envoie le message.
Neurone post-synaptique
2ème neurone → celui qui reçoit le message.
Centres nerveux
= Cerveau + moelle épinière. Ils traitent et envoient les messages.
Cortex cérébral
Couche superficielle du cerveau où sont traitées les informations.
Intégration cérébrale
Traitement simultané de différentes informations par le cerveau.

⚡ Nature du message nerveux

À retenir :

Dans un neurone → message ÉLECTRIQUE

Entre 2 neurones (synapse) → message CHIMIQUE (neurotransmetteurs)

Comment fonctionne une synapse ?

① Signal électrique arrive aux terminaisons du neurone A (pré-synaptique)

② Des neurotransmetteurs sont libérés dans la synapse

③ Ils se fixent sur des récepteurs du neurone B (post-synaptique)

④ Un nouveau signal électrique naît dans le neurone B

🔬 Le neurone – sens du message

Le message circule TOUJOURS dans ce sens :
Dendrites → Corps cellulaire → Axone → Terminaisons

🏃 Trajet d'un message nerveux (mouvement)

Stimulus (ex : ballon)
↓
Organe sensoriel (yeux)
↓
Nerfs sensitifs
↓
Centres nerveux (cerveau)
↓
Moelle épinière
↓
Nerfs moteurs
↓
Muscles → Mouvement ✅

🧩 Rôle du cerveau

Cortex cérébral
Couche superficielle du cerveau. Il traite toutes les informations reçues.
Cortex préfrontal
Zone spécialisée dans la concentration et la gestion des émotions.
Aire de Broca
Zone spécialisée dans le langage.
Comment les aires communiquent-elles ?

Via des réseaux de neurones qui transmettent les informations au niveau de leurs synapses.

⚠️ Nerf vs Neurone

NEURONE= 1 cellule nerveuse microscopique
NERF= des centaines de milliers d'axones regroupés

🍺 Effets de l'alcool

L'alcool = substance psychoactive :

→ Perturbe les synapses → message nerveux modifié

Occasionnel : mauvaise coordination, réflexes diminués → risque accidents

Régulier : troubles sommeil + mémorisation → décrochage scolaire
