1. Imparfait – emploi Q4

Quand utiliser l'imparfait ?
• Action en cours dans le passé (durée, description)
• Action répétée ou habituelle dans le passé
• Décor ou contexte d'un récit
✅ Pendant qu'il lisait, son ami est entré. → action en cours interrompue
✅ Chaque matin, il mangeait une pomme. → habitude
Terminaisons imparfait (tous les verbes) :
-ais / -ais / -ait / -ions / -iez / -aient
💡 Test : si on peut dire "en train de" ou "tous les jours" → imparfait.

3. Conditionnel présent – verbe "aller" Q9

4. Conditionnel passé – "nous aurions" Q17

Formation : conditionnel présent de AVOIR ou ÊTRE + participe passé
Avec AVOIR :
j'aurais / tu aurais / il aurait
nous aurions / vous auriez / ils auraient
Avec ÊTRE :
je serais / tu serais / il serait
nous serions / vous seriez / ils seraient
✅ Nous aurions chanté si on avait eu le temps. → fait qui ne s'est pas réalisé.
💡 "nous aurions" = conditionnel passé de AVOIR. Identifier cela à l'examen !

5. Subjonctif présent – emploi + "être" Q13 & Q14

Quand utiliser le subjonctif ?
• Après verbes de volonté, souhait, doute, sentiment
• Après : il faut que / bien que / pour que / avant que
✅ Je veux qu'il soit à l'heure. (vouloir → subjonctif)
✅ Il faut que tu fasses tes devoirs.
❌ Pas de subjonctif après : je pense que / il dit que → indicatif
PronomÊTRE au subjonctif présent
que jesois
que tusois
qu'il/ellesoit
que noussoyons
que voussoyez
qu'ils/ellessoient
💡 Irrégulier à apprendre par cœur : sois / sois / soit / soyons / soyez / soient
