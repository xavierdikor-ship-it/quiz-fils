Quiz Orthographe

Francais 5eme - 12 questions

1. Elle est ... (partir) hier.
partie : auxiliaire ETRE, accord avec le sujet feminin singulier 'elle'.
2. La lettre qu'il a ... (ecrire) est belle.
ecrite : auxiliaire AVOIR + COD 'que' (= la lettre, feminin) place AVANT le verbe.
3. Ils ont ... (chanter) toute la nuit.
chante : auxiliaire AVOIR, le COD n'est pas place avant le verbe. Pas d'accord.
4. Il ... faim et va ... la boulangerie. (a / a avec accent)
a / a-accent : 'a' = verbe avoir (test : avait). 'a-accent' = preposition (non remplacable).
5. ... part demain. (on / ont)
On : pronom sujet. 'Ont' serait une faute (ont + infinitif est impossible ici).
6. ... chien aboie, les voisins ... ennuyes. (son / sont)
Son / sont : 'son' = determinant possessif. 'sont' = verbe etre (test : etaient ennuyes).
7. Des yeux ... (bleu + clair) :
bleu clair : couleur composee de deux mots = toujours invariable.
8. Nous ... (placer) les chaises.
placons avec cedille : verbe en -cer, cedille devant 'o' pour garder le son [s].
9. Nous ... (manger) souvent ici.
mangeons : verbe en -ger, on garde le 'e' devant 'o' pour garder le son [zh].
10. ... est-il alle ? Ici ... la-bas ? (ou / ou-accent)
Ou-accent / ou : 'ou-accent' = lieu ou heure. 'ou' sans accent = ou bien (choix).
11. 'Les fleurs appartiennent a Marie.' ... fleurs sont belles.
Ses : determinant possessif (les fleurs de Marie). 'Ces' = demonstratif, ne convient pas.
12. J'... (appeler) - bonne orthographe :
appelle : verbe en -eler, doublement du 'l' devant 'e' muet (j'appelle, tu appelles...).
