Partie 1 — QCM (6 questions · 6 pts)
1Quelle est la différence entre une migration et une migration forcée ?
B. La migration = déplacement massif, volontaire ou non. La migration forcée = contraint par une cause (guerre, dictature, crise climatique). Les réfugiés sont des exemples de migrants forcés.
2La Triade désigne les 3 pôles dominants de la mondialisation. Lesquels ?
B. Triade = Amérique du Nord + Europe occidentale + Asie-Pacifique. Piège : la Russie est dans les BRICS, pas dans la Triade.
3Apple conçoit ses produits aux USA, les fait fabriquer en Chine et les vend dans le monde entier. Apple est…
C. Apple est une FTN : présente dans plusieurs pays (conception USA, production Chine, vente mondiale). L'ONU est un acteur politique, pas économique.
4Un envoi de données via internet (streaming, réseaux sociaux) est un exemple de…
D. Internet = flux immatériel d'informations. Marchandises = objets physiques. Personnes = migrations, tourisme. Capitaux = argent, investissements.
5Un pays peu connecté aux échanges mondiaux, qui profite peu de la mondialisation, est dit…
C. Espace marginalisé. Peu de flux, peu d'investissements, souvent source de migrations. À l'opposé : la Triade (centres). Entre les deux : les BRICS (émergents).
6Lequel de ces éléments fait partie d'un paysage selon la définition du cours ?
B. Un paysage = ce que nos yeux voient = aménagements humains ET/OU éléments naturels. Une autoroute + forêt = parfait exemple (aménagement humain + nature). Une carte ou un tableau n'est pas un paysage.
