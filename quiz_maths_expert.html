1. Simplifie et réduis : 4x + 3y - 2x + 5y - x =
x + 8y : 4x - 2x - x = 1x ; 3y + 5y = 8y. Résultat : x + 8y.
2. Résous : 3(x + 4) = 21
x = 3 : 3x + 12 = 21 → 3x = 9 → x = 3. Vérif : 3(3+4) = 3×7 = 21 ✓
3. Résous : 2x - 5 = x + 3
x = 8 : 2x - x = 3 + 5 → x = 8. Vérif : 2×8-5 = 11 = 8+3 ✓
4. Additionne : 2/3 + 3/4 (PPCM = 12)
17/12 : 2/3 = 8/12 et 3/4 = 9/12. 8/12 + 9/12 = 17/12.
5. Multiplie : (3/5) × (10/9) =
2/3 : (3×10)/(5×9) = 30/45. Simplification : PGCD(30,45)=15 → 30/45 = 2/3.
6. Divise : (4/7) ÷ (2/3) =
6/7 : diviser = multiplier par l'inverse. (4/7) × (3/2) = 12/14 = 6/7.
7. Triangle rectangle : cathètes 6 cm et 8 cm. Hypoténuse = ?
10 cm : Pythagore : c² = 6² + 8² = 36 + 64 = 100. c = √100 = 10 cm.
8. Angles alternes-internes formés par deux droites parallèles et une sécante : que valent-ils ?
Ils sont égaux : propriété fondamentale des angles alternes-internes avec des droites parallèles.
9. Série : 2, 4, 4, 6, 8, 10, 12. Calculer la moyenne.
6,57 (approx) : somme = 2+4+4+6+8+10+12 = 46 ; 46 ÷ 7 = 6,57.
10. Série rangée : 3, 5, 7, 9, 11, 13. Médiane = ?
8 : 6 valeurs (pair). Médiane = (7+9)/2 = 16/2 = 8.
11. Un quadrilatère a 3 angles de 85°, 110° et 70°. Le 4e angle = ?
95° : somme des angles d'un quadrilatère = 360°. 360 - 85 - 110 - 70 = 95°.
12. Classer par ordre croissant : 7/10, 2/3, 3/4 (PPCM = 60)
2/3 < 7/10 < 3/4 : 2/3=40/60, 7/10=42/60, 3/4=45/60. Ordre : 40 < 42 < 45.
13. Résous : 5(2x - 3) = 3x + 6
x = 3 : 10x - 15 = 3x + 6 → 7x = 21 → x = 3. Vérif : 5(6-3)=15 = 3×3+6=15 ✓
14. PGCD(36, 48) = ?
12 : 36 = 2²×3² et 48 = 2⁴×3. Facteurs communs : 2²×3 = 12.
15. Simplifier 36/48 au maximum ?
3/4 : PGCD(36,48)=12. 36÷12=3 et 48÷12=4. Fraction irréductible : 3/4.
